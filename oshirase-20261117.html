案件・見積・在庫

1見積を変えずに、ジョイントネジ・目隠しネジを増減できます新機能

事務の判断でネジの数を増やしたり減らしたりできます。見積書・請求書・金額は一切変わりません。

操作 案件管理 → 案件の 詳細 → 🔩 ネジの調整 → 「調整（＋/−）」に増やす数（例 12）または減らす数（例 -6）を入れて 💾 保存
  • 仮押さえ一覧・出荷指示書・出荷済み一覧・部材内訳は、調整後の「出荷する数」で出ます。出荷指示書の備考には「ネジの調整 +12」のように出ます。
  • 仮押さえ・受注確定の案件は、保存した時点で在庫を押さえ直します（足りない分は発注待ち）。
  • 「出荷指示書送付済」にしたとき、調整分も含めて在庫から引き落とします。差し戻すと戻ります。
  • 見積に無いネジは ＋ ネジを追加 で選べます。減らせるのは見積の数までです。
⚠ 「出荷指示書送付済」の後は直せません。その後に増やす分は、今までどおり案件の「予備パーツ」で持ち出しを入力してください。

2新品の製品をサンプルとして出せます（帳票なし）新機能

いつもの見積と同じく顧客と製品・倉庫を選び、🎁 サンプル出荷（帳票なし） を押すと、サンプルとして登録されます（番号は SP-）。

  • 在庫を仮押さえし、案件管理で「出荷指示書送付済」へ進めたときに在庫から引き落とします。
  • 見積書・出荷指示書・請求書などの帳票は出ません。売上集計・入金アラートにも入りません。
  • 案件一覧では「🎁 サンプル」の印が付きます。

サンプルが戻ってきても、在庫には戻しません。

3倉庫間移動で出荷指示書を出せます新機能

例：新柏から尼高へ在庫を移すとき、新柏あての出荷指示書を出せます。新柏→第一、尼高→本社など、どの倉庫の組み合わせでも使えます。

操作 案件管理 のタブの右の 🔄 倉庫間移動の登録 → 移動元・移動先・製品ライン・部材と数を入れて 🔄 登録 → 案件の 📄帳票 で出荷指示書を出す → 倉庫へ送ったら「出荷指示書送付済」へ進める
  • 登録すると移動元の在庫を押さえます（番号は MV-）。出せる帳票は移動元あての出荷指示書だけです。
  • 出荷指示書の納品先には、移動先の倉庫名と住所が入ります。住所・電話は倉庫ごとに記録され、次回から自動で入ります。
  • 「出荷指示書送付済」にした時点で、移動元から引き落として移動先の在庫に入ります。差し戻すと両方の倉庫が元に戻ります。
  • 見積書・請求書は出ず、売上にも入りません。

部材在庫一覧の「🔄 倉庫間移動（取り寄せ）」（出荷指示書なしで1部材ずつ動かす）も今までどおり使えます。

春先モード（ピンクの画面）

4案件ごとに「👷 作業登録」ができます新機能

当社の誰が・いつ・どの案件の設置に行くか、外注（人工）をどの業者に何人頼んでいるかを登録できます。

操作 🌸 春先 → 案件管理 → 案件の 👷 作業登録 → 作業日・時間・作業員を選んで 💾 保存
  • 時間は 1日 午前 午後 時刻指定 から選びます。数日かかる設置は ＋ 別の日を追加。
  • 当社の作業員は、システムのアカウントがある人から選びます。
  • 外注（人工）は ＋ 業者を追加 で業者と人数を入れます。「📋 発注書一覧」の人工に発注書があれば、選んでひも付けられます（作業日が同じものに ★）。
  • 同じ人が同じ時間帯に2件入ると ⚠ が出て、保存の前にも確認が出ます。

登録・変更は、営業の方も含めて誰でもいつでもできます（倉庫別の編集権限とは関係ありません）。

5「📅 作業カレンダー」で全体を見られます新機能

春先の案件管理のタブの並びの右端に 📅 作業カレンダー を追加しました。

  • 月表示：日ごとに案件名・当社の作業員（👷）・外注の業者と人数（🤝）。日の右上に「当社○・外注○人」の合計。
  • 週（人別）：作業員ごとに1行で、誰がいつ空いているかが分かります。
  • 予定を押すと作業登録が開いて直せます。作業員・業者で絞り込めます。🖨 印刷 はA4横。
  • 下に業者別の延べ人数（発注書のひも付けの有無も）が出ます。

6片岡さんの優先は「尼高・関西」になりました変更

春先の画面で、尼高・関西の倉庫だけを使う案件・在庫は、片岡さんがログインしている間は片岡さんだけが編集できます（その間、岩上さん・高山さんは閲覧のみ）。

  • 関西と別の倉庫が混ざった案件は、今までどおり岩上さん・高山さん優先です。
  • 案件管理の「🌸 倉庫」の切り替えは 🏭 尼高・関西 それ以外（混在を含む） になりました。

使い方は、システムのヘッダーの ❓ 使い方 で「ネジ」「サンプル」「倉庫間移動」「作業カレンダー」などと入れても出てきます。

不明な点・動きがおかしい点があれば、案件番号と、画面のどこで何をしたかを添えてご連絡ください。

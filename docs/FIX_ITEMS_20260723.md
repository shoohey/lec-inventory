## A. 計算ロジック（①⑨⑩）

### ① ネジ計算のサイズ別更新
顧客の新ネジ計算表はサイズ群別にシートが分かれ、係数が異なる。現行 `calcScrewNeeds`（index.html:968-1007）は SML 前提の統一係数（パーソナル系2倍・常設系4倍）で、**サイズ引数を受け取っていない**（呼出 4352 行は `blocks[0], tp[0], hasSideJt[0]` のみ）。

新表の係数（C3=列数, C4=段数, F3=欠損個数, F4=欠損段数, サイドJ=段数×2）:

| シート | ジョイントネジ | 目隠しネジ |
|---|---|---|
| SMLパーソナル(サイドあり) | (列-1)×段×2 → 必要=(計算値-欠損個数×2)+サイドJ必要×2 | (段×6-サイドJ)×2+2 → 必要=欠損段×2+計算値 |
| SMLパーソナル(サイドなし) | (列-1)×段×2 → 必要=計算値-欠損段×2 | (段×6)×2 |
| SML常設 | (列-1)×段×**4** | (段×6+3)×2 |
| SS 3Sパーソナル(サイドあり) | (列-1)×段×2（SML同様） | ((段×2-サイドJ)×2+2)×**2** → 必要=欠損段×2+計算値 |
| SS 3Sパーソナル(サイドなし) | (列-1)×段×2 | ((段×2)+2)×2 |
| SS 3S常設 | (列-1)×段×**2** ←現行は4 | (段×2+2)×2 |
| XL常設 | (列-1)×段×**8** ←現行は4 | ((段×6)×2+3)×2 |
| SSα常設 | (列-1)×段×4 | ((段×4)+2)×2 |
| （サイドジョイント/パーソナルのみ） | 段×2 → 必要=段×2-欠損段 | |

**変更方針**: `calcScrewNeeds` にサイズ群（sml / ss3s / xl / ssa）引数を追加し、シート別係数テーブルで分岐。呼出側（4352行）で `sz[0]` を渡す。
**維持する既存仕様（顧客OK済）**: 台湾製・日本製Ver.1はネジ在庫なし→自動入力せず参考表示のみ（`lineStocksPart` 1009-1021行）。目隠しネジ自動入力はグレー欄。
**注意**: SS/3S常設は係数半減、XL常設は倍増 → 過去案件は再計算しない（保存値維持）方針でよいか実装時に確認。

## 顧客確認事項（7/30定例 or チャット）

1. **⑤SSW**: バックボード2は「SSバックボード」でよいか。対象ライン（日本製Ver.2のみ？）。出荷指示書テンプレは既存SS流用でよいか。
2. **⑳複数サイズ**: 出荷指示書は「サイズごとに別シート/別ファイル」でよいか。色配分・ネジ計算はサイズごとに独立でよいか。
3. **⑨送料**: 中継料3万円は原価に含めるか見積側加算か（現行=見積側加算）。予備箱30kg換算は全倉庫共通か。
4. **①ネジ計算**: SS/3S常設の係数半減・XL常設の倍増は過去案件に遡及しない（保存値維持）でよいか。
5. **⑱粗利**: 原価表のアップロード形式（品番,原価のCSV/Excel想定でよいか）。5区分の「本体」に扉・サイド等の板物全部を含める区分定義の確認。
6. **⑮件名**: 「Mサイズ 30台」形式でよいか（商品名を頭に付けるか: 例「MYプラスチックロッカー Mサイズ 30台」）。
7. **追B顧客属性**: 属性の選択肢は自由入力かマスタ管理か。
8. **⑥表記**: 括弧内サイズ表記は「上下共通ボード（SML）/（SS・3S）/（Sα）」でよいか。

## 付録1: 送料計算の言語化仕様（顧客Excel図形テキスト全文の要旨）

**A. 新柏・尼高・札幌から発送**
1. サイズ別の部材枚数（サイドボード/バックボード/扉/上下共通ボード/ベースボード/棚板）を入力。3SはSSサイズとして入力。
2. 部材ごとに 箱数=枚数÷ケース入数（端数保持）、実重量=箱数×ケース実重、容積重量=箱数×ケース容積 を積算。容積重量(kg)=縦×横×高さ(cm)÷280(㎥)、端数0.5kg切上げ。
3. 注文台数に応じた追加箱数を加算（表1）: 1〜30台→1箱 / 31〜50→2 / 51〜100→3 / 101〜200→4 / 201〜300→6 / 301〜500→10。予備箱は1箱約30kgで計算。
4. 混載便: 各倉庫の運賃表（3新柏=第一貨物 / 5尼高=西濃 / 7札幌=西濃）で「距離帯×㌔数(実重量と容積重量の大きい方)」の交差=地別運賃。
5. チャーター便: 表2の制限（2t=実重1500kg/容積3000kg、4t=実重2500kg/容積6500kg）で車格選択→距離帯で料金。記載のない地域は近い距離の料金。遠距離は2t車なし。
6. 運賃原価=地別運賃＋諸経費（西濃は諸経費＋燃料サーチャージ）。1000kg超は着点チャーター便費用3万円プラス（中継料）。**見積記載運賃=運賃原価×1.1**。

**B. 本社・関西営業所から発送（ヤマト）**
1. 部材枚数入力は同じ。**1箱ごとに料金**がかかる。
2. 箱サイズはサイドボードのケースサイズ（3辺計）で決定: **L→160サイズ / M→140 / S→140 / SS→120 / 3S→120**。
3. 運賃原価=該当サイズ×配送先地域の1箱料金×箱数。見積記載運賃=×1.1。
（例: Lサイズ2台を本社→都内: 160サイズ×東京=¥1,290、箱数2 → 原価¥2,580、見積¥2,838）

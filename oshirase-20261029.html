八木熊様への発注書

1「📝 八木熊 発注書」で発注書を作れます新機能

作りかた 部材在庫一覧 → 在庫表・仮押さえ一覧・出荷済み一覧の行の右端にある 📝 八木熊 発注書
→ 件名・納品場所・納品希望日・担当を入れる → 品目の「数量」欄に個数を入れる
→ 📊 Excel（八木熊様へ送る） または 🖨 PDF（印刷画面）
  • 品目は八木熊様の注文書と同じ167品目です。「SML」「SS・3S・SSα」「入力した品目だけ」で絞り込めます。
  • 単価は2026年12月改定の八木熊新価格です。小計・消費税・合計（税込）は自動で出ます。
  • Excelは八木熊様の注文書の形のまま出ます。数量の無い行は隠すだけで消しません。右側の黄色の欄が八木熊様の回答欄です。
  • PDFは数量のある品目だけの注文書です。印刷画面で送信先を「PDFに保存」にしてください。
  • 単価が未設定の品目や、入数で割り切れない数量があるときは、出力の前に確認が出ます。
  • 入力途中の内容はその端末に残ります。在庫や案件には何も書き込みません。閲覧のみの方も使えます。
「社内備考欄」は社内用のメモです。Excel・PDFには載りません。八木熊様へのお願いは、メールの本文に書いてください。

2品番・品名・単価の手修正と、一覧に無い品目の追加新機能

  • ✏ 品目を手修正 を押すと、品番・サイズ・品名・扉色・カギ枠・本体色・入数・単価を書き換えられます。直した欄はオレンジ色になり、↺ で元に戻せます。
  • ＋ 品目を追加 で、一覧に無い品目を足せます。Excelでは一覧の最後の行の下に入り、合計にも含まれます。
  • 単価が「未設定」の品目（SSα扉・SSコネクター・アジャスターなど）は、手修正で単価を入れてから出してください。

4「📋 発注書一覧」で出した発注書を確認できます新機能

見かた 部材在庫一覧 → 右端の 📝 八木熊 発注書 の下にある 📋 発注書一覧
  • PDFを出した発注書が記録されます（全員で同じ一覧を見られます）。同じ発注日・件名で出し直すと上書きされます。
  • 🖨 PDF 📊 Excel で、そのときの内容の発注書をもう一度出せます。件名・納品場所・担当で探せます。
  • 八木熊様の回答Excelを取り込んだ発注書には「取込済」と出ます。
Excelを出しただけでは一覧に残りません。発注したときはPDFも出して控えにしてください。

八木熊様からの回答

5八木熊様の回答Excelを入庫予定に取り込めます新機能

取り込みかた 部材在庫一覧 → 入庫予定 → 📥 八木熊の回答Excel → 返ってきたExcelを選ぶ
→ 確認画面で入庫予定日・数量・入庫先倉庫を確かめる → ✅ 入庫予定に登録
  • 入庫先倉庫は納品場所から自動で決まります（例：尼高運輸 → 尼高倉庫）。確認画面で変えられます。
  • 確認画面で日付・数量を直せます。登録しない品目は 除く で外せます。
  • 品目は品番（無ければ品名・色）で在庫の部材（日本製 Ver.2）に結びつきます。
  • 入庫予定日ごとに1件の入庫予定ができます。届いたら、これまでどおり 入庫処理 で在庫に入れてください。
  • 春先の画面で取り込むと、春先の入庫予定に入ります。

6取り込みのルール（分納・未定・取り込み直し）

  • 分納：回答欄の①②（八木熊様が③④…と列を足した場合も）の日付・数量ごとに入庫予定を作ります。
  • 未定：回答の数量が発注数より少ない分や、日付が「未定」の品目は「入庫日未定」で登録します。日付が決まったら、新しい回答を取り込み直すか、入庫予定を編集してください。
  • 取り込み直し：同じ発注の回答をもう一度取り込むと、前回の入庫予定を置き換えます。入庫処理が済んだ分はそのまま残ります。
  • ベース（レール含む）は、ベース＋サイドレール×2＋バックレール×1 で入ります。取っ手プレートはトッテ（井門）、ヒンジキャップはヒンジカバーに入ります。
  • スプリング・アジャスター・スライドレバー・ヒンジピンは在庫表に部材が無いため、確認画面で部材を選ぶか「除く」にしてください。
どの発注の回答かは、発注日と件名で見分けています。発注書には分かりやすい件名を付けてください。

不明な点・動きがおかしい点があれば、画面のどこで何をしたかを添えてご連絡ください。八木熊様からの回答Excelで取り込めないものがあれば、そのExcelもお送りください。
